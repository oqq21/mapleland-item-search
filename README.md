# 메랜 아이템검색

별도 검토 앱: https://ma-4ekdhbuwxiz5vst3zkkufa.streamlit.app/

화면 버전: `2026-11-10-search-v4`. 이름 아래 스탯1·2·3을 묶어 배치하고, 입력을 바꾼 뒤 Tab 등으로 칸을 나가면 자동 검색합니다. 거래·보석 필터는 버튼형이며 새 검색 때 전체로 초기화합니다. 보석값은 12종 전체를 큰 창으로 보여줍니다. 최근 검색·기본옵·도움말은 펼침 버튼 안에 있습니다. 결과 목록이 남은 화면 높이를 채우고 목록 안에서 스크롤합니다.

가격 표시는 만 단위 정수로 반올림하며 계산용 원본 금액은 유지합니다. 무보석 추가합은 총스탯 끝의 `[ 24 ]` 형식, 남은 업횟은 1 이상일 때 총스탯 안의 빨간 `업2` 형식입니다. 작횟은 아이템명 오른쪽 `3작` 형식으로 표시합니다. 거래·보석 버튼은 Tab으로 이동한 뒤 좌우 방향키와 Space/Enter로 조작할 수 있습니다.

이 저장소는 새 검색 앱입니다. 실행 파일은 `streamlit_app.py`입니다.
기존 서비스의 GitHub Release에서 판매중·판매완료 parquet과 보석 시세를 **읽기만** 합니다.
검색에는 메랜지지 판매·구매 API를 호출하지 않고, 외부 **검색페이지 열기** 링크만 제공합니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

Streamlit Cloud: 이 저장소의 `main`, `streamlit_app.py`로 배포합니다.
테스트: `python -m pip install pytest` 후 `python -m pytest -q`.

## 이번 반영 내용

1. 본체 총스탯과 보석을 분리 표시. 보석 포함 토글은 검색 판정에만 사용.
2. 법사 합에 마력 포함. `마·인·인트`는 합마. 법신은 추가 합.
3. 정확값·이하·이상·구간 검색, 스탯 줄임말, 잘못된 입력 안내.
4. 작 방향은 보석 제외 추가치. 노작은 기본 업횟과 남은 업횟 비교.
5. 무보석만 추가옵 합 표시. 물방·마방·MP·회피는 일반 표시에서 숨기되 계산에 유지.
6. 직업·부위 공통 검색, 신망토 세부 별칭, 단도 기본 힘 필터.
7. 직업·부위별 필수·보조 보석, 등급·1억 경계·무기 보석 비중 검사.
8. 보석 옵션별 글자색, 무효 사유. 일반 무보석 무기는 누락 경고 없음.
9. 인정 보석원가를 100% 뺀 보석제외가. 리버스는 보석 재료값만 인정.
10. 이름 색상에 마력 포함. 무보석의 다음 색상 도달 가능성은 별도 접두어.
11. 확실한 판매소요만 시간으로 표시하고 나머지 완료 매물은 미확인으로 표시. 2분 이하 빨강, 완료 보라. 상태는 판매중·판매완료·만료 세 가지이며 만료 예정·남은 시간 열은 숨김. 완료와 판매중 연결 시 중복 제거.
12. 최신순. 판매소요 확인 가능한 완료 매물은 연결 판매중 수집시각으로 정렬.
13. 새 검색·기록 선택 시 결과 맨 위와 첫 페이지. 100건씩 표시하고 parquet 필터를 먼저 적용.

## 기준 자료와 갱신

- `resources/item_catalog.json`: newitemp 기준 기본옵·업횟. 값이 0이어도 덮어씁니다.
- 원본 item.xlsx에만 있는 품목은 남겨 두되 출처를 `item`으로 구분합니다. 기본 업횟이 없으면 노작으로 추정하지 않습니다.
- 카탈로그 재생성: `python scripts/export_catalog.py --newitemp "전체경로/newitemp.xlsx"`.
- 원본 parquet의 총스탯은 유지하고 추가치는 새 기본옵으로 다시 계산합니다.
- 데이터는 임시 캐시에 저장합니다. `PP213_DATA_CACHE_DIR` 환경변수로 위치를 바꿀 수 있습니다.
- 기존 내려받기 동작만 유지합니다. 화면 동작 시 한 시간 간격으로 변경 여부를 확인하며, 별도 주기 실행기는 없습니다. 자동 갱신 정책 변경은 이번 범위에 포함하지 않았습니다.

## 시간의 한계

날짜는 패킷 수집일, 시분초는 패킷 내부 시각을 사용합니다. 자정 경계를 보정하고 수집 지연이 10분을 넘으면 판매소요는 미확인으로 둡니다.
등록기간 필드가 없으므로, 3일 등록을 확실히 역산할 수 있는 매물만 확정합니다. 하루 정도 남은 매물은 늦게 발견한 3일 매물일 수 있어 추정하지 않습니다.
같은 옵션·가격의 후보가 여러 개여도 판매소요는 미확인입니다. 미확인 매물에 빠른 판매 표시를 붙이지 않습니다.

## 원본 보존

이 앱은 수집가공·기준생성 코드나 원본 Release에 쓰지 않습니다.
기존 저장소에서 넘어온 게시 스크립트(`publish_*`, `update_parquet.py`, `build_packet_web_data.py`)와 구형 API 모듈은 앱에서 사용하지 않습니다. 새 검색 앱을 실행·배포하는 데 이 스크립트를 실행할 필요가 없습니다.
